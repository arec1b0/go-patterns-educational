# Go Patterns Educational Repository

This repository contains hands-on examples of common Go programming patterns and concurrency techniques. Each lesson is self-contained in its own directory, with code and explanations.

## Lessons

- [`workerpool`](./workerpool): Simple worker pool pattern for parallel job processing.
- [`practical_exercise`](./practical_exercise): Strategy, Factory, and Worker Pool patterns in a realistic task processing scenario.
- [`pipeline`](./pipeline): Channel-based pipeline for staged data processing.
- [`singleton`](./singleton): Thread-safe singleton pattern for configuration.
- [`factory`](./factory): Factory pattern for logger creation.
- [`error_wrapping`](./error_wrapping): Idiomatic error wrapping and custom error types in Go.

## How to Use

Each lesson contains a README and a runnable Go source file. To try an example:

```sh
cd <lesson-directory>
go run *.go
```

## Prerequisites
- Go 1.18 or later
